# SuperChat MVP

Project structure:

- [backend](/Users/sudhirkumar/Documents/Codex/2026-04-24/let-s-design-a-real-mvp/backend) for the Node.js, Express, MongoDB, Socket.IO, and Razorpay server
- [frontend](/Users/sudhirkumar/Documents/Codex/2026-04-24/let-s-design-a-real-mvp/frontend) for the React frontend

## Run Backend

```bash
cd backend
npm install
npm run dev
```

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```
